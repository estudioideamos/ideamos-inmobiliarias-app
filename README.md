# Ideamos Inmobiliarias

Landing comercial de la plataforma web y de gestión para inmobiliarias de Estudio Ideamos.

## Sitio público

https://estudioideamos.github.io/ideamos-inmobiliarias-app/

## Desarrollo

```bash
npm install
npm run dev
npm test
npm run build:pages
```

## Rutas principales

- `/`
- `/la-plataforma/`
- `/funcionalidades/`
- `/tokko-broker/`
- `/beneficios/`
- `/preguntas-frecuentes/`
- `/precios/`
- `/contacto/`

La publicación en GitHub Pages se prepara con `scripts/prepare-github-pages.mjs`.
